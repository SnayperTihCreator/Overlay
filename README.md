
# Overlay — Модульная оверлей-система

[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![UI](https://img.shields.io/badge/UI-PySide6-orange.svg)](https://www.pyside.org/pyside-6)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Package Manager](https://img.shields.io/badge/Packages-uv-purple.svg)](https://github.com/astral-sh/uv)

**Overlay** — это мощная и гибкая платформа для создания и отображения виджетов (плагинов) поверх других приложений и игр. Благодаря модульной архитектуре, асинхронному ядру и современному стеку технологий, приложение обеспечивает высокую производительность и безграничные возможности для кастомизации.

## 🚀 Ключевые возможности

*   **Модульная архитектура**: Добавляйте новую функциональность с помощью плагинов. Каждый плагин — это независимый виджет или окно.
*   **Продвинутая система тем**: Полностью меняйте внешний вид оверлея и всех его компонентов с помощью CSS-подобных файлов стилей (`.qss`).
*   **Глобальные горячие клавиши**: Назначайте сочетания клавиш для быстрого доступа к функциям оверлея и плагинов из любого места системы.
*   **Удаленное управление через WebSocket**: Встроенный WebSocket-сервер позволяет управлять оверлеем из других приложений, скриптов или даже с другого устройства.
*   **Встроенный CLI**: Плагины могут регистрировать собственные команды, которые можно вызывать удаленно через WebSocket API для выполнения сложных действий.
*   **Удобная конфигурация**: Все настройки хранятся в читаемом формате `.toml`, что упрощает их редактирование и перенос.
*   **Системный трей**: Приложение удобно сворачивается в системный трей, откуда его можно снова вызвать или закрыть.

## 🛠️ Установка и разработка

Проект использует `uv` для управления зависимостями и виртуальными окружениями.

**Требования:**
*   **Python 3.11+**
*   **[uv](https://github.com/astral-sh/uv)** (рекомендуется)

**Шаги по установке:**

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <ссылка-на-ваш-репозиторий>
    cd <имя-папки-репозитория>
    ```

2.  **Создайте виртуальное окружение и установите зависимости:**
    ```bash
    uv sync
    ```

3.  **Запустите приложение:**
    ```bash
    uv run src/overlay.py
    ```

## ⌨️ Как пользоваться

*   **Основная горячая клавиша**: `Shift + Alt + O` (можно изменить в настройках). Эта комбинация показывает и скрывает главное окно оверлея.
*   **Главное меню**: В левой части экрана находится список доступных плагинов. Активируйте их, устанавливая галочки.
*   **Настройки плагинов**: Кликните правой кнопкой мыши по плагину в списке, чтобы открыть контекстное меню для доступа к настройкам, дублирования или удаления виджета.
*   **Системный трей**: Когда главное окно скрыто, иконка приложения активна в системном трее. Через нее можно снова показать оверлей или полностью его закрыть.

## 🔌 Плагины

Плагины — это сердце оверлея. Они позволяют расширять его функциональность практически безгранично.

**[Репозиторий официальных плагинов](https://github.com/SnayperTihCreator/OverayPlugins)**

В репозитории вы найдете:
*   Готовые к использованию плагины.
*   Инструменты и шаблоны для разработки собственных плагинов.

## 👨‍💻 Скрипты сборки

Проект использует `taskipy` для автоматизации задач. Вы можете запускать их через `uv run`.

*   **Сборка основного приложения:**
    ```bash
    uv run task build
    ```

*   **Сборка CLI-инструмента:**
    ```bash
    uv run task build-cli
    ```

Собранные исполняемые файлы появятся в папке `dist/`.
